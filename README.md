# Carlos Andres Lozano Gonzalez Web Profile

A bilingual personal portfolio for English II at UniEspinal. I adapted the academic web profile template to present my education, skills, and projects in Spanish and English.

## Live page

https://carlos24mk.github.io/carlos-web-profile/

Use the ES / EN button to switch languages. The page includes Home, About, Skills, Resume, Projects, and Contact.

## Technologies

HTML, CSS, and JavaScript. No framework or build step is required for this portfolio.

## Projects

- Personal Web Profile: this bilingual portfolio.
- Match Educativo: an educational web project in progress, with a user registration API built with PHP and Laravel. Source: https://github.com/carlos24MK/match-educativo
- Laravel Greeting Workshop: an academic route, controller, and Blade view exercise. Source: https://github.com/carlos24MK/taller-de-laravel

The two Laravel projects link to their public source repositories. They do not have live demos linked from this portfolio.

## Files

- index.html: page sections and links.
- style.css: layout, colors, and responsive styles.
- script.js: Spanish and English text, language switch, menu, and skill bars.
- images: profile photo and portfolio screenshot.
- NOTES.md: translation reflection and tool declaration.

## Run locally

Open index.html in a browser, or serve this folder with a local static web server. Edit matching keys in the ES and EN dictionaries in script.js to update the bilingual content.

## Publication

GitHub Pages serves the main branch from the repository root. After updating the repository, verify the live page in an incognito window, on a computer, and on a phone.
